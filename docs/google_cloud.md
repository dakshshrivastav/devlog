Gemini Enterprise Agent Platform provides model APIs, platform REST and RPC APIs, client libraries, and command-line tools to build, deploy, and manage AI agents, generative AI applications, and machine learning workflows. This page highlights key model API references---such as the Interactions API, Live API, and APIs for embeddings, tuning, and evaluation---alongside RAG and platform SDK references across Agent Platform.

<br />

## Model APIs

Interact with Gemini and other generative AI models for text and
multimodal generation, real-time streaming, embeddings, customization, and
evaluation.

### [Interactions API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/interactions-api)


Use a unified, stateful, and streaming interface to interact with models and agents.

### [Live API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/multimodal-live)


Stream low-latency, bidirectional voice and video interactions with Gemini models.

### [Embeddings APIs](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/text-embeddings-api)


Generate text and multimodal embeddings for semantic search, classification, and retrieval.

### [Tuning API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/tuning)


Customize model behavior using supervised fine-tuning.

### [Gen AI evaluation API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/evaluation)


Evaluate generative AI models and agents programmatically using rubrics and metrics.

## RAG APIs

Ground model responses and connect your agents to external data sources using
Retrieval-Augmented Generation (RAG).

### [RAG API v1](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/rag-api-v1)


Manage RAG corpora, import files, and retrieve relevant context with RAG Engine.

### [Retrieval and generation output of RAG](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/rag-output-explained)


Understand the structure of retrieval queries and grounded generation responses.

## Platform APIs

Use SDKs, command-line tools, and service-level APIs to manage
Agent Platform resources, infrastructure, and developer environments.

### [Client libraries](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/sdks/overview)


Build with the Google Gen AI SDK and Agent Platform SDK in Python, Go, Java, Node.js, and C#.

### [REST API reference](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest)


Explore all HTTP REST resources and methods for Agent Platform services.

### [RPC API reference](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rpc)


View gRPC service definitions and protocol buffer messages for Agent Platform.

### [gcloud CLI reference](https://docs.cloud.google.com/sdk/gcloud/reference/ai)


Manage Agent Platform resources from the command line.

### [Agent Platform in express mode](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/express-mode/api-reference)


Prototype and test generative AI capabilities using streamlined REST endpoints and an API key.

### [MCP reference](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/use-agent-platform-mcp)


Connect Model Context Protocol (MCP) clients and agents to Agent Platform tools.

### [Agent Retrieval](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search-2/reference/rest)


Build, manage, and query high-scale vector similarity search indexes.

### [Agent Gateway](https://docs.cloud.google.com/service-mesh/docs/reference/network-services/rest/v1/projects.locations.agentGateways)


Configure and govern network traffic between agents, MCP servers, and external tools.

### [Agent Platform Workbench](https://docs.cloud.google.com/gemini-enterprise-agent-platform/notebooks/workbench/reference)


Manage notebook instances and development environments using REST, RPC, CLI, and client libraries.
